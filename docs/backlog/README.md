# Backlog

Rascunhos das issues do projeto. Cada arquivo tem título, etiquetas, coluna do Kanban e critérios de aceite.

Criar tudo no GitHub (depois de conectar):

```bash
node tools/criar_issues.js            # só mostra o que faria
node tools/criar_issues.js --apply    # cria etiquetas e issues
```

O arquivo é a fonte até a issue existir; depois a issue do GitHub passa a valer.
